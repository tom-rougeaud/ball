# Abel Run v2

Jeu de course minimaliste en pseudo-3D (canvas, fichier unique, sans bibliothèque). Doigt, pavé tactile (joystick) ou flèches. 5 niveaux (curseur vert › rouge), routes parallèles, rampes et ponts, tunnels, monolithes, boosts, ciel qui change, intro animée, boutique (pièces, billes à motifs, traînées, pistes, 10 univers) et caméra calée sur l’axe de la piste.
